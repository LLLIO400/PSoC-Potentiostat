# 3D 打印外壳（STEP 模型）

整机实拍效果见仓库首页照片。全部为 STEP 通用格式，主流切片软件（Cura / PrusaSlicer / Bambu Studio 等）可直接导入。

| 文件 | 用途 |
|---|---|
| `恒电位仪外壳.step` | 主壳体，容纳 CY8CKIT-059 开发板与接线 |
| `恒电位仪上盖.step` | 顶盖，与主壳体配合 |
| `恒电位仪电极转接板支架1.step` | 电极转接板立柱支架（最终版配合手拧螺丝固定电极，见首页照片） |
| `恒电位仪电极转接板支架2.step` | 电极转接板支架另一件，与支架1 配对使用 |
| `ep管支架.step` | EP 管（离心管）支架 |

**打印材料**：本项目实际使用 **PETG**（韧性更好；照片中的半透明蓝色外壳即 PETG 打印）。PLA 亦可（无耐热需求）；支架类小件建议 0.2 mm 层高、≥25% 填充保证强度。

**配套 PCB**：电极转接板打板文件见 [`../PCB转接板打板文件/`](../PCB转接板打板文件/)。
