# SPE 电极 PCB 转接板（打板文件）

把丝网印刷电极（SPE）的 **1.25 mm 4-pin FPC 座**转接到**排针**，引出 WE / RE / CE 三电极接 PSoC——即说明文档（`PSoC-Potentiostat-YI-1.0_upgrade_guide.md`）2.1 节"SPE 接口：1.25 mm FPC 插座 + 自制转接板"方案的实物。

| 文件 | 说明 |
|---|---|
| `New_Project_..._PCB2_20260818_103302.zip` | 立创 EDA 导出的打板文件，可直接在嘉立创（JLC）下单制板 |
| `仿真图_(顶层).png` | 顶层渲染预览 |
| `用来转接这种4pin的FPC座（插电极）和排针（接电线）.png` | 所转接的 FPC 座与排针实物对照 |

**安装**：FPC 座焊在转接板一侧插 SPE 电极，排针侧用杜邦线接 PSoC 的 WE → P0.0 / RE → P3.4 / CE → P3.6（完整接线见说明文档"接线总表"一节）；固定到 3D 打印支架上使用（见 [`../3D打印外壳/`](../3D打印外壳/)）。
